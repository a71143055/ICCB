7) 목표 : 경제 자립 / 취미 생활 / 기술 증진 / 회원 모집 / 카페 창업 /  / 의미 부여

3. 블로그 디자인 환경
================================================================
1) 개발환경 : PYTHON
2) 구현환경 : NETLIFY
3) 로그인 환경 : NETLIFY 에 의한 로그인 및 회원가입으로 등록 가능 - 중복 차단
4) 로그인 및 소개 라인 : 소개 / 프로필 작성 / 회원 가입 / 로그인
5) 분야 구성 바 : 주류 & 젤리 에스프레소 / 과일 & 채소 - 스무디 & 케이크 / 특색 케이크
6) 등록된 사람들의 분야별 문서 등록 창 : 분야 구성 바 선택시 들어가게 되어 있음.
7) 문서 작성 페이지 : 들어가서 구글 문서 시스템을 기반으로 정리하고 공유할 수 있음.

4. 목표
================================================================
1) 경제 자립 : 이제는 배우고 학습할 때는 지났다. 이젠 사람들과 뭔가를 해야 한다.
2) 취미 생활 : 사실 취미 생활이 경제 자립 수단이고, 그 중 아르바이트로라도 벌어야 한다.
3) 기술 증진 : 기술에 돈을 들이거나 스스로 개척해서 바리스타로의 첫 걸음 준비 중이다.
4) 회원 모집 : 회원들과 함께 원활한 소통을 함으로써 본 블로그의 가치를 증명한다. 
5) 카페 창업 : 블로그를 통해 얻은 노하우로 에스프레소 바/랩 창업에 의의를 둔다.
6) 샘플 완성 : 해당 블로그 개발의 최고의 예시로 기록이 남을 것이고, 이를 발판 삼음.
7) 의미 부여 : 결론적으로 해당 블로그 운영했다는 기록으로 스스로의 정체성을 확립한다.
